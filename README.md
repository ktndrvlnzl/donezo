# Donezo

> Get it done!

Donezo is a simple to-do list web app designed to help you organize tasks, deadlines, priorities, and categories in one place.

## Live Demo

[Open Donezo](PASTE-YOUR-LIVE-LINK-HERE)

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete
- Set due dates
- Set priorities
- Organize tasks by category
- Search tasks
- Filter tasks
- Sort tasks by deadline
- View task history
- Calendar view
- Drag and drop tasks
- Local storage
- Responsive design

## Built With

- HTML
- CSS
- JavaScript
- Local Storage

## How It Works

Donezo stores your tasks locally in your browser using Local Storage, so your tasks remain available even after refreshing the page.
