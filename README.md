# Donezo
> Get it done!

Donezo is a simple to-do list web app designed to help you organize tasks, deadlines, priorities, and categories in one place.

## Live Demo
[Open Donezo](https://ktndrvlnzl.github.io/donezo/)

## Features
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as complete
- Set due dates
- Set priorities (High / Medium / Low)
- Organize tasks by category
- Recurring tasks (daily, weekly, monthly)
- Search tasks
- Filter tasks by category
- Sort tasks by deadline
- Drag and drop to reorder tasks
- Completed task history
- Calendar view
- Dark mode
- Editable display name
- Progress tracker (X of Y tasks done, % completed)
- Local storage — tasks, name, and dark mode preference are saved automatically
- Responsive design (mobile and desktop)

## Built With
- HTML
- CSS
- JavaScript
- Local Storage API

## How It Works
Donezo stores your tasks locally in your browser using Local Storage, so your tasks — along with your name and dark mode preference — remain available even after refreshing the page or closing the tab.
